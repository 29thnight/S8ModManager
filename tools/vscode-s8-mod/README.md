# S8 Mod Tools

삼국지 8 REMAKE with 파워업키트의 S8ModManager API 21용 모드 제작 도구입니다.

1. VS Code 명령 팔레트에서 **Install from VSIX...**를 실행해 패키지를 설치합니다.
2. 명령 팔레트에서 **S8: 새 모드 만들기**를 실행합니다.
3. 모드 매니저가 설치된 게임 폴더를 선택하고 모드 이름과 ID를 입력합니다.
4. 실행 중인 게임에서 **시작 화면 → 편집**을 열고 입력한 이름의 메뉴를 누릅니다. 편집 화면이 이미 열려 있다면 닫았다가 다시 엽니다.

모드는 `scripts/mods/<id>`에 만들어집니다. `source/Mod.cs`에서 인사 문구를 바꿔 동작을 확인할 수 있습니다. 게임의 JIT 로더가 소스를 컴파일합니다. 함께 생성되는 프로젝트는 VS Code에서 C# 자동완성 및 오류 표시를 사용하기 위한 것입니다.
